\section{Introduction}

This is a dummy document for testing the LaTeX + draw.io build
environment. It is compiled from the repository root with
\texttt{make}, so all paths (e.g.\ \texttt{figures/}) are relative to
the repository root.

Figure~\ref{fig:example} is exported from
\texttt{drawio/example.xml} by running \texttt{make xps} (or
\texttt{make xp example}) before \texttt{make}; \texttt{make
allwithfigs} does both in one go.
